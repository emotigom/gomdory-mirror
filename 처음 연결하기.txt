곰도리 미러 · 처음 연결하기
================================

준비물
- Windows 10 또는 Windows 11 노트북
- Android 태블릿 또는 휴대전화
- 데이터 전송을 지원하는 USB C-to-C 또는 C-to-A 케이블
- 노트북과 TV를 연결할 HDMI 케이블

최초 1회 설정
1. Android 기기에서 설정 → 휴대전화 정보/태블릿 정보로 이동합니다.
2. 빌드번호를 빠르게 7번 누릅니다.
3. 설정으로 돌아가 개발자 옵션 → USB 디버깅을 켭니다.
4. USB 케이블로 Android 기기와 노트북을 연결합니다.
5. 기기에 승인 창이 뜨면 “이 컴퓨터에서 항상 허용”을 선택하고 허용을 누릅니다.

제조사별 빌드번호 위치
- Samsung: 기기 정보 → 소프트웨어 정보 → 빌드번호
- Google Pixel / Lenovo / Motorola: 기기 정보 → 빌드번호
- Xiaomi / Redmi / POCO: 내 기기 → OS 버전을 7번 누른 뒤 추가 설정 → 개발자 옵션
- 그 밖의 기기: 설정 검색에서 “빌드번호” 또는 “개발자 옵션”을 찾습니다.

수업 시작
1. 노트북과 TV를 HDMI로 연결합니다.
2. Windows 키+P를 누르고 복제를 선택합니다.
3. 압축을 푼 폴더의 “곰도리 미러 시작.cmd”를 실행합니다.
4. Android 태블릿이나 휴대전화를 USB 케이블로 연결합니다.
5. 프로그램에 “연결 완료”가 보이면 “화면 열기”를 누릅니다.
6. 준비 창이 사라지고 “곰도리 미러” 영상 창 하나만 나타납니다.

화면은 주강사가 Android 기기에서 직접 조작합니다.
보조강사 노트북은 화면을 TV로 전달하는 역할만 합니다.

수업 종료
- 기본 창 모드에서는 영상 창 오른쪽 위 X를 한 번 누릅니다.
- 전체 화면 모드에서는 Alt+F4를 누릅니다.
- 종료하면 준비 창으로 돌아옵니다. 자동으로 다시 연결하지 않습니다.

연결되지 않을 때
- Android 기기 잠금을 해제합니다.
- 충전 전용이 아닌 데이터 전송용 케이블인지 확인합니다.
- 기기의 USB 알림에서 파일 전송을 선택합니다.
- 제조사에 맞는 Windows USB 드라이버를 확인합니다.
  https://developer.android.com/studio/run/oem-usb
- 학교 관리 기기에서 개발자 옵션이 차단되었는지 확인합니다.

오류 기록 보내기
- 앱에서 “문제가 있을 때만 열기 · 진단 기록”을 열고 “기록 복사”를 누릅니다.
- 또는 %LOCALAPPDATA%\GomdoryMirror\gomdory-mirror.log 파일 내용을 보냅니다.

보안
- 개인 소유가 아닌 Android 기기에서는 관리자 허가를 먼저 확인하세요.
- 수업 후 USB 디버깅을 끄거나 USB 디버깅 승인을 취소할 수 있습니다.
