# Android 공통 지원 설계

## 지원 경계

| 항목 | 지원 범위 |
|---|---|
| 송출 기기 | Android 5.0(API 21) 이상 휴대전화·태블릿 |
| 수신 PC | Windows 10/11 64-bit |
| 연결 | USB C-to-C, C-to-A 데이터 케이블 |
| 화면 조작 | Android 기기에서 직접 조작하는 보기 전용 |
| 동시 연결 | 여러 기기 감지 후 송출 기기 한 대 선택 |
| 네트워크 | 미러링에 Wi-Fi 불필요 |

iPhone/iPad, USB 디버깅이 차단된 관리 기기, 충전 전용 케이블은 지원 범위 밖입니다.

## 연결 상태 모델

| 상태 | 앱의 처리 |
|---|---|
| 기기 없음 | 데이터 케이블·USB 디버깅 설정 안내 |
| 승인 대기 | Android 기기의 RSA 승인 창 안내 |
| 오프라인 | 잠금 해제·케이블 재연결 안내 |
| 연결 완료 | 제조사·모델·기기 유형·Android 버전 표시 |
| 여러 대 연결 | 일련번호로 구분하고 송출 기기 선택 제공 |
| 지원 버전 미만 | Android 5.0 이상 필요 안내 |
| ADB 오류 | 사용자 안내와 진단 기록을 분리해 제공 |

## 기기 판별

1. `adb devices -l`에서 일련번호·상태·모델·USB 전송 정보를 안전하게 분리합니다.
2. 승인된 기기에서 Android 시스템 속성을 한 번만 읽어 캐시합니다.
3. 화면의 짧은 변 길이를 dp로 환산해 휴대전화와 태블릿을 구분합니다.
4. 여러 대가 연결되어도 선택한 일련번호를 scrcpy의 `--serial`에 명시합니다.

개인정보나 화면 내용은 수집하지 않습니다. 기기 정보 캐시는 앱 실행 중 메모리에만 유지됩니다.

## 제조사 대응

Samsung 전용 드라이버 링크를 제거하고 Android 공식 OEM USB 드라이버 안내로 통합합니다. 앱 내부의 처음 연결 안내는 다음 계열을 우선 다룹니다.

- Samsung Galaxy
- Google Pixel
- Lenovo / Motorola
- Xiaomi / Redmi / POCO
- 그 밖의 Android 제조사

드라이버를 프로그램에 직접 묶지 않습니다. 제조사별 라이선스와 관리자 권한 문제를 피하고, 필요한 사용자만 공식 안내에서 설치하도록 합니다.

## 현장 검증 순서

1. 승인된 Galaxy Tab에서 연결·화면 열기·한 번 종료를 확인합니다.
2. 승인 전 Android 휴대전화에서 RSA 승인 안내 전환을 확인합니다.
3. 휴대전화와 태블릿을 동시에 연결해 기기 선택을 확인합니다.
4. Pixel 또는 Motorola 계열에서 Windows 드라이버 안내를 확인합니다.
5. Xiaomi 계열에서 개발자 옵션 진입 안내와 화면 송출을 확인합니다.
6. 각 기기에서 30분 송출, 회전, 케이블 분리 후 재연결을 확인합니다.
