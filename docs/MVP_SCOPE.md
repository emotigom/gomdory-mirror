# v0.3 Android 공통 현장 검증 범위

## 기준 환경

- 송출 기기: Android 5.0 이상 Galaxy·Pixel·Lenovo·Motorola·Xiaomi 계열 태블릿 또는 휴대전화
- 수신 기기: Windows 10/11 64-bit 노트북
- 외부 화면: 노트북 HDMI에 연결된 TV 또는 프로젝터
- 연결: USB C-to-C 또는 C-to-A 데이터 케이블

## 성공 기준

1. 앱을 먼저 실행해 둔 상태에서 Android 기기를 연결하면 8초 안에 모델·기기 유형·상태가 표시된다.
2. 이미 승인한 기기는 `화면 열기` 한 번으로 미러링이 시작된다.
3. 최초 연결 기기는 승인 방법을 즉시 안내한다.
4. 기본 상태에서 노트북 입력으로 Android 기기를 조작할 수 없다.
5. Wi-Fi를 끈 상태에서도 30분 이상 화면이 유지된다.
6. 케이블 분리 후 다시 연결하면 준비 창에서 재연결할 수 있다.
7. 화면 회전과 Android 멀티윈도우 전환이 송출 화면에 반영된다.
8. Windows 화면 복제 모드에서 노트북과 HDMI TV에 같은 화면이 안정적으로 표시된다.
9. 여러 Android 기기가 연결되면 목록에서 송출 기기를 선택할 수 있다.
10. 영상 창의 X 또는 Alt+F4 한 번으로 프로그램 전체가 종료되고, CMD로 즉시 다시 실행할 수 있다.

## 현재 하지 않는 일

- iPhone/iPad 지원
- 무선 미러링을 기본 연결로 제공
- 학교 관리 정책 우회
- USB 디버깅 승인 우회
- 원격 인터넷 전송
- 사용자 화면 또는 개인정보 수집
